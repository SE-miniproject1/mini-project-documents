# Blood Bank Management System — Deliverable 1

Software Engineering Mini Project, PES University.
Organisation: [SE-miniproject1](https://github.com/SE-miniproject1)

A web-based system for managing donor registration, blood collection and
screening, inventory, hospital requests, donation camps, and reporting.

Repository structure and full documentation are being added incrementally.
See open pull requests for work in progress.
